# _arquivo/ — arquivos antigos (não publicados)

Cópias antigas que nenhuma página usa mais. Foram tiradas da raiz do repositório
para não serem publicadas em `floriatan.com.br/web/` (item I34 do `PENDENCIAS.md`
do site principal):

| Arquivo | Por que saiu |
|---|---|
| `assets/` | as páginas usam `/assets/` do site principal |
| `js/app.js` | as páginas usam `/js/app.js` do site principal |
| `robots.txt` | sem efeito: os buscadores só leem o `robots.txt` da raiz do domínio |

A pasta não é publicada (começa com `_` e está em `exclude` no `_config.yml`).
Pode ser apagada quando não houver mais motivo para guardar essas cópias; o
histórico do Git mantém o conteúdo de qualquer forma.
